# help — 技能导航

当用户说"有哪些 skill"、"你能做什么"、"有什么功能"、"help"时，输出以下分类列表。

输出时保持分类清晰，每个 skill 一行描述。

---

## 📊 业务分析

| 命令 | 用途 |
|------|------|
| `/business-analysis` | 讨论一个业务功能要不要做、怎么做、多少工作量（7 步框架） |
| `/deep-research` | 深度网络调研，多来源查资料写报告 |

## 🔧 代码开发

| 命令 | 用途 |
|------|------|
| `/superpowers` | 通用功能开发实现 |
| `/code-review` | 审查代码 diff，找 bug + 优化建议 |
| `/simplify` | 只做代码简化重构，不找 bug |
| `/security-review` | 安全审查 |
| `/coding-tutor` | 教学模式，手把手教写代码 |

## 🎨 特定领域

| 命令 | 用途 |
|------|------|
| `/flutter-gen` | 生成 Flutter 页面/组件 |
| `/frontend-design` | Admin 后台前端页面设计 |
| `/ai-intent-debug` | AI 意图分类问题排查 |

## 🛠 工具

| 命令 | 用途 |
|------|------|
| `/excalidraw-diagram` | 画架构图/流程图/时序图 |
| `/verify` | 启动 app 验证改动是否正常 |
| `/run` | 启动项目看看效果 |
| `/skill-creator` | 创建新的 skill |
| `/update-config` | 配置 Claude settings |
| `/fewer-permission-prompts` | 减少权限确认弹窗 |
| `/claude-api` | Claude/Anthropic API 参考查询 |
| `/dataviz` | 数据可视化/图表 |
| `/keybindings-help` | 快捷键设置 |

## 🔁 自动化

| 命令 | 用途 |
|------|------|
| `/loop` | 定时重复执行某个任务 |
