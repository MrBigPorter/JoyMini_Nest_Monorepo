# Contact Support

> **This is the fallback document** — if no specific policy matches the user's question, guide them to contact support.

| Method | Details | Availability |
|:-------|:--------|:-------------|

| **Email** | support@joymini.com | Response within 24 hours |
| **Phone** | 02-8888-7777 | Mon-Sat, 9AM-6PM |
| **Facebook** | fb.com/JoyMiniPH | Mon-Sat, 9AM-6PM |

## What to Prepare

When contacting support, please have the following ready:

1. **Order number** (if the issue is about an order)
2. **Account email** or **registered mobile number**
3. **Screenshots** or photos of the issue
4. **Payment reference** (if the issue is about payment)

## Common Issues You Can Resolve Yourself

| Issue | Where to Go |
|:------|:------------|
| Track order | My Orders → Select order |
| Cancel order | My Orders → Cancel (before shipped) |
| Request return | My Orders → Request Return |
| Change address | My Orders → Edit Address (before shipped) |
| Reset password | Login → Forgot Password |
| Check coupon status | Account → My Vouchers |
| Update profile | Account → Profile |
| View wallet history | Account → Wallet → History |

## Frequently Asked Questions

**Q: How long does support take to respond?**
A: Chat responses are usually within **5-10 minutes**. Email responses within **24 hours**.

**Q: Do you support Tagalog?**
A: Yes! Our support team speaks **English**, **Tagalog**, and **Cebuano**.

**Q: Can I request a call back?**
A: Yes. Use the in-app chat to request a callback. We will call you within **30 minutes** during business hours.

**Q: Is there a physical store I can visit?**
A: JoyMini is currently **online-only**. All support is handled through the channels listed above.

## Still Need Help?

If you cannot find the answer to your question in our knowledge base, please contact our support team using any of the methods above. We're here to help! 🇵🇭
