# Coupon Rules

## Coupon Types

| Type | Description | Example |
|:-----|:------------|:--------|
| Fixed Discount | Deducts a fixed amount | ₱100 off |
| Percentage Discount | Deducts a percentage | 20% off |
| Free Shipping | Waives shipping fee | Free shipping |
| Cashback | Returns amount as wallet credit | ₱50 cashback |
| Bundle Deal | Discount on multi-item purchase | Buy 2 get 10% off |

## How to Use a Coupon

1. Add items to your cart.
2. Go to **Checkout**.
3. In the **Coupon / Promo Code** field, enter your code.
4. Click **Apply**.
5. The discount will be reflected in the order total.

## Coupon Conditions

| Condition | Details |
|:----------|:--------|
| Minimum spend | Coupon only applies if order total ≥ minimum amount |
| Valid period | Coupon must be used before the expiry date |
| Usage limit | Some coupons are limited to **first N users** |
| Per user | Some coupons are **one-time use** per account |
| Stacking | Most coupons **cannot** be combined with other promos |
| Exclusions | May not apply to Flash Sale / Lucky Draw items |

## Common Coupon Issues

| Issue | Reason | Solution |
|:------|:-------|:---------|
| "Code not found" | Typo or expired | Double-check spelling. Try copying the code directly |
| "Minimum spend not met" | Order total too low | Add more items to reach the minimum |
| "Not applicable" | Item excluded | Check the coupon terms |
| "Already used" | One-time use | Each code can only be used once per account |
| "Expired" | Past validity date | Check the expiry date in My Vouchers |

## My Vouchers

- All your unused coupons are listed in **Account → My Vouchers**.
- Each voucher shows: discount amount, minimum spend, expiry date, and terms.
- Expired vouchers are automatically removed.

## Coupon Abuse Policy

- **Coupon stacking**: Using multiple accounts to claim the same coupon repeatedly is prohibited.
- **Fake referrals**: Creating fake accounts for referral coupons is prohibited.
- **Violation**: Accounts found abusing coupons may have all discounts reversed and be suspended.
