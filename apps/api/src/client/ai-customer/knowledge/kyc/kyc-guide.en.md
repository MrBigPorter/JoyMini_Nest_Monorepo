# KYC Guide — Account Verification

## Why Verify Your Account?

| Level | Requirements | Benefits |
|:------|:-------------|:---------|
| Level 0 (Unverified) | None | Browse products only |
| Level 1 (Basic) | Phone number + Email | Place orders, use coupons |
| Level 2 (Standard) | Level 1 + Valid ID + Selfie | Wallet withdrawal, lucky draw |
| Level 3 (Advanced) | Level 2 + Proof of address | Higher withdrawal limits |

## Accepted IDs

| ID Type | Front Photo | Back Photo | Remarks |
|:--------|:-----------|:-----------|:--------|
| Philippine Passport | ✅ | ❌ | Must be valid |
| UMID / Unified ID | ✅ | ✅ | Both sides |
| Driver's License | ✅ | ✅ | Both sides |
| PRC ID | ✅ | ❌ | Front only |
| Postal ID | ✅ | ❌ | Front only |
| Senior Citizen ID | ✅ | ❌ | Front only |
| National ID (PhilSys) | ✅ | ✅ | Both sides (digital version accepted) |

## How to Verify (Step by Step)

1. Open the app and go to **Account → Verification**.
2. Choose your verification level.
3. Upload the required documents.
4. Take a **live selfie** for face matching.
5. Submit. Our team will review within **24 hours**.

## Verification Status

| Status | Meaning |
|:-------|:--------|
| Pending | Documents submitted, waiting for review |
| Verified | All documents approved |
| Rejected | Documents did not meet requirements (see reason) |
| Expired | ID has expired, please upload a new one |

## Common Rejection Reasons

| Reason | Solution |
|:-------|:---------|
| Blurry photo | Retake with good lighting, ensure all text is readable |
| Expired ID | Use a valid, non-expired ID |
| ID mismatch | The name on the ID must match your account name |
| Selfie doesn't match | Ensure you are in a well-lit area, no sunglasses or mask |
| Incomplete document | Upload **both sides** if required |
| Edited/screensho | Upload the **original photo**, not a screenshot of a photo |

## Privacy & Security

- Your documents are **encrypted** and stored securely.
- Documents are only used for **verification purposes**.
- You can request **deletion** of your KYC data by contacting support.
- We **never share** your documents with third parties.
