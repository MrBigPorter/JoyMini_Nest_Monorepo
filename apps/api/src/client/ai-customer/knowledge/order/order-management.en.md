# Order Management

## Order Statuses

| Status | Description |
|:-------|:------------|
| Pending Payment | Order created but not yet paid |
| Paid | Payment confirmed, waiting for processing |
| Processing | Seller is preparing your order |
| Shipped | Package is with the courier |
| Delivered | Package has been delivered |
| Completed | Order finalized (after 7 days of delivery) |
| Cancelled | Order was cancelled |
| Refunded | Payment has been returned |

## How to Cancel an Order

1. Go to **My Orders** page.
2. Find the order and click **Cancel**.
3. Select a cancellation reason.
4. Submit.

**Important**: Orders can only be cancelled **before** they are shipped. Once shipped, you need to request a return instead.

## How to Track an Order

1. Go to **My Orders** → Select order.
2. View the **Tracking** section for real-time updates.
3. Click the tracking number to open the courier's tracking page.
4. You can also cancel tracking updates via **SMS**.

## How to Confirm Receipt

- Orders are automatically marked as **Completed** **7 days** after delivery.
- You can manually confirm receipt earlier by going to **My Orders** → **Confirm Receipt**.
- Once confirmed, the seller receives payment (minus platform fees).

## How to Leave Feedback

1. Go to **My Orders** → **Completed** tab.
2. Click **Write Review** on the order.
3. Rate the product (1-5 stars) and write a review.
4. Submit. You can also upload photos.

## Order Issues

| Issue | Solution |
|:------|:---------|
| Wrong item received | Request a **return** within 24 hours |
| Missing item | Contact **support** with photos of the package |
| Damaged item | Request a **refund** within 48 hours |
| Never arrived | Contact **support** after 7 days of no tracking update |
| Charged incorrectly | Contact **support** with payment screenshot |
