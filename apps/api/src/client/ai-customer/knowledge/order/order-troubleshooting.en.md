# Order Troubleshooting

## Payment Failed

**Possible causes**:
- Insufficient balance in GCash / PayMaya / wallet
- Bank declined the transaction
- Daily transaction limit reached
- Network timeout

**Solutions**:
1. Check your balance and try again.
2. Use a different payment method.
3. Wait 5 minutes and retry.
4. If the amount was deducted but order shows unpaid, contact support with your payment reference number.

## Cannot Cancel Order

**Possible causes**:
- Order is already shipped
- Order is in "Processing" state

**Solutions**:
1. If shipped: Request a **return** instead via My Orders → Request Return.
2. If processing: Contact support to request cancellation.
3. For group buying orders: Cancellation only possible before group is formed.

## Order Not Updating

**Possible causes**:
- Courier hasn't scanned the package yet
- Weekend/holiday delay
- Technical delay in tracking system

**Solutions**:
1. Wait **24 hours** — most tracking updates appear within a day.
2. Contact the courier directly with your tracking number.
3. If no update for **5 days**, contact JoyMini support.

## Wrong Amount Charged

1. Check the **Order Details** page for the price breakdown.
2. Verify if any **coupon** or **discount** was applied.
3. Check for **shipping fees** (may vary by location).
4. If still incorrect: Contact support with screenshots of the order page and payment receipt.

## Item Damaged on Delivery

1. **Do not** accept the package — refuse delivery with the courier.
2. If already accepted: Take **photos** of the damage within **24 hours**.
3. Go to My Orders → Request Return → select "Damaged item".
4. Upload the photos and submit.
5. We will process a **full refund** including shipping within **48 hours**.

## Multiple Charges

If you were charged more than once for the same order:

1. Check your transaction history in GCash/Bank app.
2. Some charges are **temporary holds** that will be released within **3-5 business days**.
3. If charges persist after 5 days: Contact support with screenshots of all charges.
