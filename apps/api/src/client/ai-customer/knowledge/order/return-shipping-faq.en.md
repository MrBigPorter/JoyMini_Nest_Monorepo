# Return Shipping FAQ

## Who Pays for Return Shipping?

| Reason for Return | Who Pays Return Shipping |
|:------------------|:------------------------|
| **Item defective / damaged** | JoyMini covers the cost |
| **Wrong item sent** | JoyMini covers the cost |
| **Item not as described** | JoyMini covers the cost |
| **Changed mind / don't like it** | **You** pay return shipping |
| **Ordered wrong size/color** | **You** pay return shipping |
| **No longer need the item** | **You** pay return shipping |

See [Refund Policy](refund-policy.en.md) for detailed return conditions.

## Return Shipping Costs

### When JoyMini Covers Shipping

If the return is due to our error (defective, wrong item, not as described):
- **Return shipping is free** — we provide a prepaid return label.
- The cost of return shipping will be **deducted from the refund** or **reimbursed separately** (depending on the situation).

### When You Pay Shipping

If the return is due to a change of mind:

| Scenario | Estimated Cost |
|:---------|:--------------|
| Standard item (small/light) | ₱50 – ₱150 |
| Large/heavy item | ₱150 – ₱500 |
| Bulky item (furniture, appliances) | ₱500 – ₱2,000 (may require special pickup) |

The exact cost depends on:
- **Item weight and dimensions**
- **Your location** and the **seller's location**
- **Shipping method** (standard or express)

### Will the original shipping fee be refunded?

| Scenario | Original Shipping Fee Refunded? |
|:---------|:------------------------------|
| Full refund (defective/wrong item) | ✅ Yes — fully refunded |
| Full refund (change of mind) | ❌ No — original shipping is not refunded |
| Partial refund (only some items returned) | ❌ No — original shipping not refunded |
| Exchange | ❌ No — you pay shipping both ways |

## How Return Shipping Works

### Option 1: Courier Pickup (Recommended)

1. Request a return via **My Orders → Return/Refund**.
2. Select the reason for return.
3. Choose **Courier Pickup** as the return method.
4. A courier (J&T, LBC, or Ninja Van) will pick up the item from your address.
5. For JoyMini-covered returns: the label is **prepaid**.
6. For buyer-covered returns: the **shipping fee is deducted from your refund**.

### Option 2: Drop-off

1. Request a return via the app.
2. Choose **Drop-off** as the return method.
3. You will receive a **return QR code** or **reference number**.
4. Drop off the package at the nearest **courier branch**.
5. Show the QR code/reference number — the label is printed on-site.

### Option 3: Self-arranged

1. Request a return via the app.
2. Choose **Self-arranged** as the return method.
3. Ship the item back using any courier of your choice.
4. Upload the **tracking number** and **shipping receipt** to the app.
5. You will be reimbursed for shipping (if JoyMini covers it).

## Return Address

The return address will be provided in the **return request confirmation**. It may be:
- **JoyMini warehouse** (for JoyMini-fulfilled items)
- **Seller's address** (for seller-fulfilled items)

**Never ship returns to an address not provided in the official return request.**

## What If...

### "The courier didn't show up for pickup"

1. Check the scheduled pickup date in your return request.
2. Most couriers attempt pickup **within 1-2 business days**.
3. If no one arrives after 2 attempts, contact support to reschedule.
4. Alternatively, switch to **Drop-off** method.

### "I already paid for return shipping — can I get reimbursed?"

If the return was due to **our error** (defective/wrong item), yes:
1. Keep the **shipping receipt** from the courier.
2. After the return is processed, contact support with the receipt.
3. We will reimburse the shipping cost via **wallet credit**.

If the return was a **change of mind**, no — return shipping is your responsibility.

### "The item was damaged during return shipping"

- If you **used our prepaid label**: We will handle the claim with the courier. You are fully protected.
- If you **arranged shipping yourself**: You need to file a claim with the courier directly. We recommend insuring valuable items when shipping them back.

### "Can I return multiple items in one package?"

| Scenario | Allowed? |
|:---------|:---------|
| Same order, multiple items | ✅ Yes — consolidate in one package |
| Different orders, same seller | ✅ Yes — contact support to combine |
| Different orders, different sellers | ❌ No — must return separately |

### "I lost the return label / QR code"

1. Go to **My Orders → Return/Refund**.
2. Tap **"View Return Details"**.
3. You can **re-download** the label or **re-generate** the QR code.
4. If still unable to find it, contact support.

### "Can I exchange instead of returning?"

Currently, JoyMini does **not** offer direct exchanges. You need to:
1. **Return** the unwanted item (follow the return process).
2. **Place a new order** for the desired item.

This ensures faster processing, as exchanges often take longer due to inventory and logistics coordination.

### "How long does return shipping take?"

| Stage | Timeframe |
|:------|:----------|
| Courier pickup scheduled | 1-2 business days |
| Item in transit to warehouse/seller | 2-5 business days |
| Item received and inspected | 1-2 business days |
| Refund initiated (after inspection) | 1-3 business days |

Total: **5-12 business days** from pickup request to refund.

## International Returns

JoyMini primarily operates in the **Philippines**. Most sellers and warehouses are Philippines-based. If you received an international order:
- Return shipping may be **more expensive** and take **longer**.
- Contact support for specific instructions.
- You may be responsible for **customs duties** on the return.
