# Account Guide

## How to Register

1. Download the JoyMini app from **Google Play** or **App Store**.
2. Open the app and tap **Create Account**.
3. Enter your **mobile number** (Philippine number required).
4. Enter the **OTP** sent via SMS.
5. Set your **password** (minimum 8 characters, including letters and numbers).
6. Complete your **profile** (name, email, birthday).
7. Done! You can now browse and shop.

## How to Log In

- **Method 1**: Use your registered **mobile number** + **password**.
- **Method 2**: Use **OTP login** — enter your number and we'll text you a code.
- **Method 3**: Use **Google** or **Facebook** login (if linked).

## How to Reset Password

1. On the login screen, tap **Forgot Password**.
2. Enter your registered mobile number.
3. Enter the OTP sent to your phone.
4. Create a new password.
5. Login with your new password.

## Account Profile

You can edit the following in **Account → Profile**:

| Field | Editable? | Notes |
|:------|:----------|:------|
| Profile Photo | ✅ Yes | Max 5MB, JPG/PNG |
| Display Name | ✅ Yes | 2-50 characters |
| Email | ✅ Yes | Used for receipts |
| Mobile Number | ❌ No | Contact support to change |
| Birthday | ❌ No | Set during registration only |
| Address Book | ✅ Yes | Add/Edit/Delete addresses |

## Account Security

| Feature | How to Enable |
|:--------|:--------------|
| Transaction PIN | Account → Security → Set Transaction PIN |
| 2FA | Account → Security → Enable 2FA |
| Login Alerts | Account → Security → Enable login notifications |
| Session Management | Account → Security → Active Sessions → Logout others |

## Account Deactivation

To temporarily deactivate or permanently delete your account:

1. Go to **Account → Settings → Delete Account**.
2. Read the information about what will be lost.
3. Confirm with your password and OTP.
4. Account will be deactivated immediately and permanently deleted after **30 days**.

**What is lost on deletion**:
- Order history (orders placed before deletion are still valid)
- Wallet balance (withdraw or use before deletion)
- Coupons and vouchers
- KYC verification data
- Saved addresses and payment methods
