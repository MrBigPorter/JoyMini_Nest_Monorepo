# Wallet Troubleshooting

## Deposit Issues

### "Deposit deducted but not credited"

| Possible Cause | What to Do |
|:---------------|:------------|
| Network delay | Wait **30 minutes**. Most delays resolve automatically. |
| Wrong reference number | Check the transaction ID matches in both apps. |
| Bank/GCash system maintenance | Check GCash/bank status page. Retry after 1 hour. |
| Amount below minimum | Some methods require minimum ₱50. |

**If still not credited after 30 minutes:**
1. Go to **Wallet → Transactions** and check if the transaction appears as "Pending."
2. Take a screenshot of the deduction from GCash/bank.
3. Contact support with: transaction screenshot, amount, date, payment method.

### "Deposit method not available"

- Your KYC level may be too low. See [Deposit Guide](deposit-guide.en.md) for limits.
- The method may be temporarily down for maintenance.
- Try a different deposit method (e.g., switch from GCash to bank transfer).

## Withdrawal Issues

### "Withdrawal failed"

| Issue | Solution |
|:------|:---------|
| Insufficient balance | Check your available balance in Wallet. |
| KYC level too low | Complete higher KYC level for larger withdrawals. |
| Daily limit reached | Wait until the next day (limits reset at midnight). |
| Bank/GCash error | Retry after 30 minutes. If still failing, contact support. |

### "OTP not received"

1. **Wait 60 seconds** and request again.
2. Check your mobile signal — poor signal may delay SMS.
3. Verify your registered mobile number in **Account → Settings**.
4. Try restarting your phone if the problem persists.
5. If still not receiving OTP, contact support to update your number.

### "Wrong amount received"

- Check the withdrawal fee was deducted. See [Withdrawal Guide](withdrawal-guide.en.md) for fee schedule.
- Verify the exchange rate if withdrawing in a different currency.
- Contact support with the withdrawal reference number if the amount is incorrect.

## Balance Issues

### "Balance missing / reduced unexpectedly"

| Possible Cause | Check |
|:---------------|:------|
| Automated withdrawal | Check your withdrawal history. |
| Refund processed | Check if a refund was credited and used. |
| Cashback expired | Some cashback has expiry dates. |
| Chargeback / fee | Check for any platform fees. |

Go to **Wallet → Transactions** — all balance changes are recorded with timestamps and descriptions.

### "Can't use wallet to pay"

- Wallet balance must be **sufficient** for the order total.
- Some payment methods (e.g., COD) cannot be combined with wallet payment.
- Minimum wallet payment: ₱50.
- Maximum wallet usage per transaction: ₱100,000.

## GCash/Bank-Specific Issues

### GCash
- GCash service hours: **24/7** (occasional maintenance 2 AM - 4 AM).
- GCash transaction limit: ₱50,000 per transaction.
- If GCash is down, try **PayMaya** or **Bank Transfer**.

### Bank Transfer
- **InstaPay**: Available 24/7. Limit ₱50,000 per transaction.
- **PESONet**: Available banking hours only. Next-day settlement for late transfers.
- If the transfer doesn't arrive within the expected time, check with your bank first.

## Still Having Issues?

If you've tried all solutions above and the problem persists:

1. Prepare your **User ID** and **transaction reference number**.
2. Contact support via in-app chat or email.
3. Include screenshots of any error messages.

See [Contact Support](../common/contact-support.en.md) for all contact options.
