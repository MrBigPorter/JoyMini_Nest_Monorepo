## 3. 合入判定

`unify-intent-thresholds` 5.3 的合入条件：

1. Top-1 降幅 ≤ 1pp —— 实际为 **+0.7pp**，满足
2. `rag` 精确率不劣化 —— 实际 78.6% → **80.0%**，满足

结论：**保留** 2.x 的融合顺序修正。

说明：153 题下 1 题的波动不足以显著（p=1），但修正消除了
「向量 0.69 + 关键词 0.90 被融合前门槛直接丢掉」的结构性缺陷，
并有单测钉住（`意图 0.69+0.90 → 0.753 进入候选集`，门槛移回融合前时用例变红）。
