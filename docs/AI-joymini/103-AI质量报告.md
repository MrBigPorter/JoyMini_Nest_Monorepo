## 4. 人工校准

- 抽检比例：2/10 = 20%（≥10%）
- 一致率：2/2 = 100%
- 标注文件：`tools/eval/task/manual-labels.jsonl`
- 标注方式：先 `--collect-only` 收集回答，人工独立标注，再 `--transcripts` 判分（judge 不参与标注）

局限：标注人只有 1 位，且是同厂 judge；一致率 100% 只能说明当前样本上判定口径一致，不能代替多标注人裁决。

## 5. 失败项与后续

| 现象 | 线索 | 后续 |
|---|---|---|
| `task-order-shipping` 找不到存在的订单 | 用户说订单号 `AIQ202611190001`，工具 `getOrderInfo` 只接受内部 `orderId` | 让订单工具支持按 orderNo 查询，或回答前先按订单号匹配 |
| `task-withdraw` 未出确认卡片 | 模型先追问渠道与账户信息 | 评估是否允许两轮收集后再出卡 |
| `task-mixed-coupons` 漏抽奖券 | 多意图只执行了一个 Agent | 与 orchestrator 多意图执行顺序一起排查 |
| judge 同厂商 | Groq / Gemini 本地 key 均被供应商判无效 | 换有效 key 后重跑同一批样本，并在报告中替换第 5 项 |
