# 104 · RAG 中文召回修复与分层验收

> 日期：2026-11-20
> 变更：`rag-chinese-recall`
> 基线：`tools/eval/rag/reports/20261119-222514.json`（topK=3）、`20261119-224613.json`（topK=5）
> 改后：`tools/eval/rag/reports/20261120-003509.json`（topK=3，最终干净一轮）、`20261119-235736.json`（topK=5）
> 结论：**保留**；关键词层 Recall 从 0 到 89.9%，全局指标不劣化；中文 1 题回退、差异不显著

---

## 1. 改了什么

- `tokenize()` 支持 CJK 二元组与中英混排，纯英文词项集合保持不变
- Layer 2 同时匹配 `document_chunks.content` 与 `knowledge_documents.keywords`，按命中数排序，空 tokens 直接返回
- Meilisearch 把 `keywords` 加入可搜索字段
- 检索接口 `debug=true` 返回四层候选与层内排名
- reranker 不可用时用 RRF（k=60）排序，替代混合原始分
- Jina 日额度从硬编码 1M 改为 `JINA_DAILY_TOKEN_LIMIT`（默认 3M），80% 预警

## 2. 数据与口径

- 黄金集：129 题（中文 79、英文 45、混合 5、负样本 20）
- 主口径：topK=3（对齐线上 `handleRagQuery`）
- reranker：Jina `jina-reranker-v3`；最终一轮日志 `provider=jina` 80 次，`provider=ollama` 0 次、`falling back` 0 次
- 环境：本地后端 + PostgreSQL/pgvector + Meilisearch + Jina

## 4. 分层召回（改后，109 道正样本）

| 层 | Recall@K |
|---|---:|
| vector | 100.0% |
| meili（BM25，含 keywords） | 41.3% |
| chunk（正文 + keywords） | 89.9% |
| doc（整文档 keywords） | 89.0% |
| keyword（chunk ∪ doc） | **89.9%** |

改前中文 query 在 `tokenize()` 后被清空：Layer 2 不执行、Layer 3 score 恒 0，关键词层实际为 0。改后关键词层成为独立可用的召回通道。

## 5. 配对检验与翻转题

基线 222514 vs 改后 003509（129 题）：

| | B 对 | B 错 |
|---|---:|---:|
| A 对 | 84 | 1 |
| A 错 | 2 | 42 |

- 净改进 +1 题
- 精确 McNemar **p = 1.0000**，不显著
- 翻转题：
  - `r107 My deposit did not arrive`：A 错 → B 对
  - `r109 What is the withdrawal fee?`：A 错 → B 对
  - `r29 怎么修改登录密码？`：A 对 → B 错（中文唯一回退）

结论：全局与关键词层方向正确，但 129 题样本下**不能宣称显著提升**；中文 -1 题属于单题波动，不应解读为系统性退化。

## 6. RRF 降级（no-rerank）

| 口径 | 改前 | 改后 |
|---|---:|---:|
| no-rerank Hit@1 | 71.6% | **78.0%** |
| no-rerank Hit@3 | 97.2% | 93.6% |
| no-rerank MRR | 0.846 | 0.857 |

RRF 把 no-rerank 的 Hit@1 拉回并超过基线，但 Hit@3 有 -3.6pp：RRF 只看排名，部分原本靠前的文档被多层累加挤出前三。生产主路径是 rerank=true，该差异只影响降级路径；需要时可单独调 `k` 或加权。

## 7. 负样本与相关性门槛

- 负样本 20 题，改前/改后误召回率均为 **100%**
- 本次没有启用最终相关性门槛，符合设计 D6：先有负样本与分数分布，再定阈值
- 后续应把“负样本 abstention ≥80%”作为门槛变更的验收项

## 8. 遗留问题

1. **线上 Jina 未配置**：VPS `JINA_API_KEY` 为空，JinaProvider 启动即禁用；生产 rerank 仍缺失
2. **Infinity 只做 embedding**：`BAAI/bge-m3`、`/v1/rerank` 404；自建 bge reranker 需要另起模型/容器
3. **英文 Hit@3 2.4pp 回退**：1 题（n=41），不显著；需更大样本确认
4. **RRF 的 Hit@3 权衡**：降级路径可接受，后续可评估加权 RRF
