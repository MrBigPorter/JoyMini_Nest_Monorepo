# 108 · AI 评测与反馈闭环

> 关联：`openspec/changes/admin-ai-quality-console/`
> 入口：admin → AI Operations → Quality / Security

## 1. 反馈分诊

- 状态：PENDING / REVIEWED / IGNORED
- 记录 reviewedBy / reviewedAt
- 操作：管理员在 `/ai-ops/quality` 标记 Reviewed/Ignore，可写备注
- 与客服工作台的显式反馈共用 `AiAnswerFeedback`

## 2. 评测集

- 数据：Dataset → Case → Run → Result
- Case：question / answer / expect（mustMention / confirmAction / forbidExecution / intent）
- Run：后台执行，API 返回 RUNNING，UI 轮询
- 失败：run.status=FAILED，summary.error 可见

## 3. Prompt 真测试

- 使用 active version 的 config 调 LLM
- 记录 actualOutput / latencyMs
- 失败仍落 test run，actualOutput 为空

## 4. 注入检测

- 命中异步写 `AiSecurityEvent`（type/mode/length/userIdHash）
- 不存原文
- 模式来自 `AI_INJECTION_DETECTION_MODE`
- 页面：`/ai-ops/security`

## 5. 口径

- 评测 judge 与被测模型默认异厂商
- 生产需 `AI_EVAL_ENABLED=true` 才允许启动 run
- 注入命中保留期后续补清理任务
