## 1. 设计原则

1. **先回答“今天哪里不对”**，再让用户看明细。
2. **运营页不出现工程术语**；工程页才允许 hash、checkpoint、JSON。
3. **每个数字必须有时间范围、口径、下钻链接。**
4. **失败不是空**：加载、空、错误、无权限、功能关闭必须分开。
5. **每个写操作必须说明影响范围。**
6. **一次只做一件事**：待办队列优先于大表格。
7. **原始数据默认折叠**。

## 4. 共享组件

### 4.1 `AiStatCard`

```text
label        指标名
value        数值
unit         单位（%、次、条、₱）
range        时间范围
delta        对比（+/-，带基期）
hint         口径
href         下钻链接
state        loading / error / empty
```

规则：

- 没有时间范围不渲染卡片
- 没有口径不渲染卡片
- `error` 显示“加载失败 + 重试”，不显示 0
- 可下钻的卡片必须有明确链接

### 4.2 `AiDataTable`

必备能力：

- 列配置
- 筛选栏
- 分页
- 行操作
- 空/错/加载/无权限/功能关闭
- 最后更新时间
- 行点击打开详情

### 4.3 `AiFilterBar`

```text
时间范围（默认 24h / 7d）
状态
类型
负责人
关键词
重置
```

时间范围必须显示时区。

### 4.4 `AiDetailPanel`

结构：

```text
摘要（一句话）
关键字段
时间线
关联对象
原始数据（折叠）
操作
```

### 4.5 `AiActionConfirm`

禁止只写“确认吗”。

必须显示：

```text
动作：暂停 AI 回复
影响：ai-processing 队列，当前排队 12 条
对象：12 个会话
不可逆：否
[取消] [确认暂停]
```

不可逆操作需要输入对象名称或数量确认。

### 4.6 `AiStateView`

```text
loading  骨架屏
empty    “暂无数据” + 下一步
error    “加载失败” + 重试 + 错误码
forbidden “无权限” + 申请入口
disabled “功能未开启” + 开启方式
```

## 5. 页面逐页结构

### 5.1 今日运营 `/ai-ops`

目标：今天哪里不对。

```text
┌──────────────────────────────────────────────┐
│ 今日运营                    数据截止 12:31:05 │
├──────────────────────────────────────────────┤
│ 待处理反馈 5   服务故障 3   误转 1   SLA 2    │
├──────────────────────────────────────────────┤
│ 今天最需要关注                               │
│ · ai_error 比昨天 +6，集中在优惠券            │
│ · “好的，麻烦你了”后误转 3 次                 │
│ · 2 个会话超过 SLA 5 分钟                     │
├──────────────────────────────────────────────┤
│ [打开质量待办] [打开转人工队列] [查看洞察]     │
└──────────────────────────────────────────────┘
```

规则：

- 每张卡可点，进入过滤后的列表
- 无异常时显示“今天暂无异常”
- 数据截止时间必显
- 快捷入口覆盖全部业务运营页

### 5.2 质量待办 `/ai-ops/quality`

三个 Tab：

```text
质量待办 | 回归测试 | 知识质量
```

质量待办：

- 一次一条
- 4 个判断
- 保存并下一条
- 来源、转人工原因、trace、RAG 来源
- **待办与系统信号分轨**：待办只放显式负反馈、服务故障、已认领条目；转人工线索、用户取消、重复追问放在页面下方“系统信号”区，只读、不计入待处理，可认领拉入待办
- 详见 [114](./114-AI质量运营-Admin设计.md)、[118 §4.3](./118-AI-Operations-验收评审与修复计划.md)

回归测试：

- 数据集卡片
- 最近通过率
- 新失败/已修复/仍失败
- 从反馈一键生成用例

知识质量：

- 文档质量
- 检索测试
- 不显示原始 JSON

```text
┌──────────────────────────────────────────────┐
│ 转人工队列                                   │
```

- 显示 SLA 阈值
- 显示负责人
- 显示转人工原因
- 可直接跳到客服工作台
- 趋势图作为次要信息

### 5.4 AI Runtime `/ai-ops/runtime`

按运营语言重排：

```text
AI 现在正常吗？
├── 正常 / 积压 / 暂停
├── 排队、处理中、失败
└── 数据截止时间

用户消息没回复
├── AI 处理失败（死信）
├── 消息没交给 AI（Outbox FAILED）
└── 每条：用户、会话、原因、[重新处理]

系统通道
├── Redis
├── 队列状态
└── [暂停 AI 回复] [清理历史任务]
```

规则：

- 默认只显示 AI 相关队列
- 原始队列名放“高级”
- Clean 默认只清 completed
- 清 failed 单独危险操作
- 每个操作显示影响范围

### 5.5 流程版本 `/ai-ops/flows`

```text
查找会话
→ 当前流程/版本/步骤
→ 选择目标版本
→ 显示变化和影响
→ 填原因
→ 确认切换
```

规则：

- 不手输 conversationId；支持用户/订单/会话搜索
- 不显示 hash
- “切换流程版本”不叫 Rollback
- 明确“不撤销已完成的退款/订单”
- 审计显示操作人姓名、版本、原因、结果

### 5.6 用量与成本 `/ai-ops/usage`

```text
Tab：用量 | 成本 | 预算

用量：
  今日 token、请求数、用户数
  日趋势
  按用户/模型

成本：
  今日成本、本月成本
  按模型/业务线
  预算进度

预算：
  日预算、月预算
  80%/100% 告警
  超限用户/会话
```

规则：

- token 和成本分开
- 超限按天判断
- 时间范围必显
- 可导出

### 5.7 客户记忆 `/ai-ops/memory`

```text
用户搜索（手机号/昵称/订单号）
→ 用户摘要
→ 记忆卡片（基本信息/偏好/业务事实）
→ 来源会话
→ 修改/软删/恢复
→ 危险操作：永久删除
```

规则：

- 不要求用户背 userId
- 展示 sourceConversationId 链接
- 单条软删可恢复
- 永久删除需要原因 + 输入确认
- 不展示原始对话

### 5.8 安全事件 `/ai-ops/security`

```text
安全事件
├── 今日命中 / 待处理 / 已拦截 / 误报
├── 事件表：时间、类型、风险、状态、用户、会话
└── 详情：命中规则、原文脱敏、处置
```

动作（判定与动作分开）：

```text
判定：确认攻击 / 标记误报
动作：加入黑名单 / 忽略同类 / 已拦截（仅 enforce 模式可用）
```

规则：

- 分页、日期筛选
- summary 跟随筛选和时间刷新；按状态的分布不随状态筛选塌缩
- 不展示未解释的 type
- 可跳转会话上下文
- **证据优先**：事件至少展示命中规则、置信度、脱敏片段、会话、脱敏用户；只有 type/length/hash 不足以判断
- **log 模式禁止“已拦截”**：当前模式只记录不拦截，写 `BLOCKED` 会产生假记录
- **判定与动作是两个维度**：要能表达“确认攻击 + 未拦截”
- 详见 [118 §5.4.3](./118-AI-Operations-验收评审与修复计划.md)

### 5.9 运营洞察 `/ai-ops/insights`

```text
AI 健康度
├── AI 解决率
├── 转人工率
├── 误转率
├── 服务故障率
└── 重复追问率
```

- 百分比显示，带分子/分母

```text
├── 用户
```

- VIEWER 不显示入口

## 8. 交互规范

### 二次确认

必须包含：

```text
做什么
影响多少对象
是否不可逆
怎么恢复
```

### 危险操作分级

```text
普通：查看、筛选、重试（无需确认）
敏感：暂停队列、切换流程（二次确认）
危险：清理失败任务、永久删除记忆（输入确认 + 原因）
```

### 错误提示

```text
不要：操作失败
要：无权限，需要 ADMIN 角色；请联系管理员开通
```

### 时间

- 页面显示本地时间 + 时区
- 指标口径写 UTC 或本地
- 数据截止时间必显
