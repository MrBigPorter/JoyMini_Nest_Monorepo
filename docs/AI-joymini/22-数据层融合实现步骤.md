# 22. 数据层融合实现步骤 — AI 消息与聊天历史同表存储

## 🎯 本步骤目标

在 **不新建表、不修改 Schema** 的前提下，实现 AI 客服消息与人工聊天消息在同一个 `ChatMessage` 表、同一个 `seqId` 时间线、同一个 Flutter 本地存储中的完整融合。

---

## 📖 背景说明

### 承上

前序文档完成了：
- [20-Flutter-AI-人工融合方案](20-Flutter-AI-人工融合方案.md) — 整体架构设计，AI Agent 转人工判断
- [21-数据层融合方案-SpecCoding分析](21-数据层融合方案-SpecCoding分析.md) — 数据模型逐字段兼容性分析

### 这一步要解决的问题

1. Flutter `MessageType` 枚举缺少 `ai(10)` 类型
2. Flutter `ChatEventHandler` 未监听 `aiReply` / `aiTransfer` 事件
3. 缺少 `AiBubble` UI 组件
4. 服务端 `ChatGateway` 缺少 `emitAiReply` 方法
5. 服务端 `AiCustomerService` 缺少 post-graph 转人工检查

### 设计决策

| 决策 | 选择 | 理由 |
|---|---|---|
| AI 消息存储 | 同一张 `ChatMessage` 表 | 零 Schema 变更，自然融入 seqId 排序和增量同步 |
| AI 消息 type | 10 | 独立 type 便于前端条件渲染 |
| 传输方式 | Socket `aiReply` 事件 | Flutter 已有完整的 Socket 架构 |
| AI 消息发送者 | `senderId=null` | 系统消息模式，无需创建虚拟用户 |

### Step 3: ChatEventHandler 新增 AI 事件监听

**文件**: `lib/ui/chat/handlers/chat_event_handler.dart`

在 `init()` 方法中新增两个 Socket 事件监听：

```dart
class ChatEventHandler {
  void init() {
    // 现有监听
    _socketService.on('chatMessage', _handleChatMessage);

    // [新增] AI 回复监听
    _socketService.on('aiReply', _handleAiReply);
    // [新增] 转人工通知监听
    _socketService.on('aiTransfer', _handleAiTransfer);
  }

  Future<void> _handleAiReply(Map<String, dynamic> data) async {
    final msg = ChatUiModel(
      id: data['messageId'],
      seqId: data['seqId'],
      content: data['content'],
      type: MessageType.ai,
      isMe: false,
      createdAt: data['createdAt'],
      conversationId: data['conversationId'],
      senderName: 'AI 客服',
      senderAvatar: 'ai_bot_avatar_url',
      meta: data['meta'] as Map<String, dynamic>?,
      status: MessageStatus.success,
    );
    await _repo.saveOrUpdate(msg);
  }

  Future<void> _handleAiTransfer(Map<String, dynamic> data) async {
    final msg = ChatUiModel(
      id: data['messageId'],
      seqId: data['seqId'],
      content: '🔄 已为您转接人工客服，请稍候...',
      type: MessageType.aiTransfer,
      isMe: false,
      createdAt: DateTime.now().millisecondsSinceEpoch,
      conversationId: data['conversationId'],
      meta: {
        'reason': data['reason'],
        'agentId': data['agentId'],
        'estimatedWait': data['estimatedWait'],
      },
      status: MessageStatus.success,
    );
    await _repo.saveOrUpdate(msg);
  }
}
```

### Step 7: AiCustomerService post-graph 转人工检查

**文件**: `apps/api/src/client/ai-customer/ai-customer.service.ts`

在 `chatStream()` 方法中，graph 执行完成后检查 `needsHumanTransfer`：

```typescript
async chatStream(conversationId: string, userId: string, message: string) {
  // 1. 执行 LangGraph
  const result = await this.graph.invoke({
    messages: [new HumanMessage(message)],
    userId,
  });

  // 2. 持久化 AI 消息到 ChatMessage 表
  const aiMessage = await this.prisma.chatMessage.create({
    data: {
      conversationId,
      senderId: null,  // 系统消息
      type: 10,        // AI 类型
      content: result.reply,
      meta: {
        intent: result.intent,
        steps: result.steps,
        needsHumanTransfer: result.needsHumanTransfer,
        transferReason: result.transferReason,
      },
      seqId: await this.getNextSeqId(conversationId),
    },
  });

  // 3. 通过 Socket 推送 AI 回复
  await this.chatGateway.emitAiReply(conversationId, {
    messageId: aiMessage.id,
    content: aiMessage.content,
    seqId: aiMessage.seqId,
    meta: aiMessage.meta as any,
    createdAt: aiMessage.createdAt.getTime(),
  });

  // 4. 如果 LLM 判断需要转人工
  if (result.needsHumanTransfer) {
    const transferMessage = await this.prisma.chatMessage.create({
      data: {
        conversationId,
        senderId: null,
        type: 11,  // 转人工通知
        content: `🔄 已为您转接人工客服。原因: ${result.transferReason}`,
        meta: { reason: result.transferReason },
        seqId: await this.getNextSeqId(conversationId),
      },
    });

    await this.chatGateway.emitAiTransfer(conversationId, {
      messageId: transferMessage.id,
      reason: result.transferReason,
    });

    await this.notifyHumanServiceQueue({
      conversationId,
      userId,
      reason: result.transferReason,
      aiSummary: result.reply,
    });
  }
}
```

### Step 8: 新增用户主动转人工端点

**文件**: `apps/api/src/client/ai-customer/ai-customer.controller.ts`

```typescript
@Post('transfer')
@UseGuards(AdminJwtAuthGuard)
async transferToHuman(
  @CurrentUserId() userId: string,
  @Body() dto: { conversationId: string; reason?: string },
) {
  // 1. 持久化转人工消息
  const transferMsg = await this.aiCustomerService.createTransferMessage(
    dto.conversationId, userId, dto.reason,
  );

  // 2. 推送转人工事件
  await this.chatGateway.emitAiTransfer(dto.conversationId, {
    messageId: transferMsg.id,
    reason: dto.reason || '用户主动请求转人工',
  });

  // 3. 通知人工客服队列
  await this.aiCustomerService.notifyHumanServiceQueue({
    conversationId: dto.conversationId,
    userId,
    reason: dto.reason,
  });

  return { success: true };
}
```
