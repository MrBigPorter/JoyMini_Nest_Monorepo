## A. 生产化 · P0（5 条，能亏钱 / 能越权）

| ID | 问题 | 后果 |
|:--:|---|---|
| P0-1 | Socket.IO 会话越权，任意登录用户可 join / 发消息到任意会话 | 跨租户窃听、冒名、拿到确认 token |

| **N-8** | **三处生产日志直接打印用户原文**（✅ 已修复 2026-11-11）：① `meilisearch.service.ts` 打印检索 query 原文；② `events.gateway.ts` dispatch 打印 payload 前 200 字（含用户消息正文）；③ `orchestrator.node.ts` 打印 `LLM decided to ask user: <文案>`。另清理 7 处 debug 日志中的原文（intent-router、intent-classifier、multi-intent-decider、ai-message.listener 等） | 修复前 `docker logs ... \| grep -c` 命中 27 条含用户原文；修复并重启后新日志仅见 `search 63 chars`、`contentLength=`、`messageLength=`，`grep -c 'content preview\|LLM decided to ask user'` → 0 | 用户对话原文进 Loki 长期留存（10 天），与 #89 FR-7 / AC-6 直接冲突 |
| **N-9** | **Socket 重连不重放 `join_chat`**（⏳ 未修复，客户端侧）：断线重连后 socket 自动回 `user_X` 私有房间，但不会重新 `join_chat` 进会话房间，服务端日志 `Room ... has 0 clients before dispatch` | 2026-11-11 实测：后端重启导致 socket.io 502 → 客户端 15:08:56 重连成功，但房间仍为空，AI 回复已入库（seqId 86）却未推送 | 任何后端发布 / 网络抖动后，用户在当前会话里收不到消息，只能退出重进 |
