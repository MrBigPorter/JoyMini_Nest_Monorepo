# Blog 页面布局规范 v1.0.0

> ✅ 所有页面布局与结构规范

---

## 1. 全局布局结构

### 1.1 基础布局

```
┌──────────────────────────────────────────────────┐
│                    Header                    64px
├──────────┬───────────────────┬──────────────┤
│          │                   │              │
│ Sidebar  │  Content Area       │  Sidebar    │
│ 256px    可变宽度            288px
│          │                   │              │
│          │                   │              │
├──────────┴───────────────────┴──────────────┤
│                    Footer                    │
└──────────────────────────────────────────────────┘
```

### 1.2 响应式布局变化

| 设备                   | 布局结构                                                         |
| ---------------------- | ---------------------------------------------------------------- |
| 📱 Mobile (< 768px)    | 单列布局: Header → Content → Footer                              |
| 📱 Tablet (768-1023px) | 两列布局: Header → [ Sidebar + Content ] → Footer                |
| 🖥️ Desktop (> 1024px)  | 三列布局: Header → [ Sidebar + Content + RightSidebar ] → Footer |
