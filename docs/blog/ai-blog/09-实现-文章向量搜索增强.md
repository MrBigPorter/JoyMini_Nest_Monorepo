### 设计决策

| 决策 | 选项 | 选择 | 理由 |
|------|------|------|------|
| 嵌入模型 | Ollama mxbai-embed-large vs OpenAI text-embedding-3-small | **Ollama mxbai-embed-large** | 本地部署、零成本、768 维与 pgvector 兼容 |
| 嵌入生成时机 | 实时生成 vs 异步队列 | **异步队列（BullMQ）** | 避免请求阻塞，支持批量重试 |
| 内容哈希算法 | MD5 vs SHA256 | **MD5** | 仅用于变更检测，不需密码学安全，性能更优 |
| 版本策略 | 覆盖 vs 版本递增 | **版本递增 + stale 标记** | 可追溯历史，支持回滚分析 |
| 搜索索引 | IVFFlat vs HNSW | **IVFFlat (lists=100)** | 适合中等规模数据集，构建快、内存占用低 |
| 多语言处理 | 统一向量 vs 分语言向量 | **分语言存储（locale 字段）** | 不同语言语义空间不同，分开搜索更准确 |

```typescript
// 替换 generateEmbedding 方法（约 641 行）
async generateEmbedding(text: string): Promise<number[] | null> {
  try {
    const providerConfig = await this.getProviderConfig();
    const embeddingModel = providerConfig.embeddingModel || 'mxbai-embed-large:latest';
    const baseUrl = providerConfig.baseUrl?.replace(/\/+$/, '') || 'http://localhost:11434';

    const response = await fetch(`${baseUrl}/api/embeddings`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        model: embeddingModel,
        prompt: text.slice(0, 8000), // 截断到模型最大 token 限制
      }),
    });

    if (!response.ok) {
      throw new Error(`Ollama embedding API error: ${response.status}`);
    }

    const data = await response.json();
    const embedding: number[] = data.embedding;

    if (!embedding || !Array.isArray(embedding) || embedding.length === 0) {
      throw new Error('Empty embedding response');
    }

    this.logger.debug(`Embedding generated: ${embedding.length} dimensions`);
    return embedding;
  } catch (error) {
    this.logger.error(`Embedding generation failed: ${error.message}`);
    // 降级：返回 null，调用方处理空结果
    return null;
  }
}
```

#### 关键说明

- **文本截断**：`mxbai-embed-large` 支持最大 512 tokens，约 2000 字符。对长文章内容，需在调用前做分块处理（由 `ArticleEmbeddingService` 处理）
- **重试策略**：利用 `generateEmbedding` 的 `try/catch` + 返回 `null` 机制，由调用方（队列任务）决定重试逻辑
- **向量维度**：`mxbai-embed-large` 输出 768 维向量，与 Prisma 模型中 `vector(768)` 一致
- **性能考量**：Ollama 嵌入生成约 50-200ms/次（取决于文本长度和硬件），建议批处理

### Step 2: 实现 ArticleEmbeddingService 完整方法

**文件**: `apps/api/src/blog/agent/services/article-embedding.service.ts`

在 02 文档的骨架基础上，实现完整的 4 个方法：

```typescript
import { Injectable, Logger } from '@nestjs/common';
import { PrismaService } from '@api/prisma/prisma.service';
import { AiService } from '@api/common/ai/ai.service';
import * as crypto from 'crypto';

@Injectable()
export class ArticleEmbeddingService {
  private readonly logger = new Logger(ArticleEmbeddingService.name);
  private readonly CHUNK_SIZE = 1500; // 每块字符数
  private readonly MAX_CHUNKS = 10;    // 最大分块数

  constructor(
    private readonly prisma: PrismaService,
    private readonly aiService: AiService,
  ) {}

  /**
   * 计算内容哈希（MD5）用于变更检测
   */
  private computeContentHash(title: string, summary: string, content: string): string {
    return crypto
      .createHash('md5')
      .update(`${title}|${summary}|${content}`)
      .digest('hex');
  }

  /**
   * 将长文本分割成块，每块最多 CHUNK_SIZE 字符
   */
  private chunkText(text: string): string[] {
    const chunks: string[] = [];
    let start = 0;
    while (start < text.length && chunks.length < this.MAX_CHUNKS) {
      const end = Math.min(start + this.CHUNK_SIZE, text.length);
      chunks.push(text.slice(start, end));
      start = end;
    }
    return chunks;
  }

  /**
   * 生成文章嵌入（含 contentHash 去重）
   */
  async generateEmbedding(articleId: string, locale: string): Promise<boolean> {
    try {
      // 1. 获取文章内容
      const article = await this.prisma.blogArticle.findUnique({
        where: { id: articleId },
        include: { translations: true },
      });

      if (!article) {
        this.logger.warn(`Article not found: ${articleId}`);
        return false;
      }

      // 2. 提取指定 locale 的内容
      const title = article.title;
      const summary = article.summary || '';
      const content = article.content || '';

      // 如果文章有翻译，优先使用翻译后的内容
      let localizedContent = content;
      let localizedTitle = title;
      if (locale !== 'zh' && article.translations?.length > 0) {
        const translation = article.translations.find((t) => t.languageCode === locale);
        if (translation) {
          const data = translation.translatedData as any;
          localizedTitle = data?.title || title;
          localizedContent = data?.content || content;
        }
      }

      // 3. 计算 contentHash，检查是否已存在相同内容的最新嵌入
      const contentHash = this.computeContentHash(localizedTitle, summary, localizedContent);

      const existingActive = await this.prisma.articleEmbedding.findFirst({
        where: {
          articleId,
          locale,
          status: 'active',
          contentHash,
        },
      });

      if (existingActive) {
        this.logger.debug(`Embedding up-to-date for article ${articleId} [${locale}]`);
        return true; // 内容未变更，跳过
      }

      // 4. 将旧版本标记为 stale
      await this.prisma.articleEmbedding.updateMany({
        where: { articleId, locale, status: 'active' },
        data: { status: 'stale' },
      });

      // 5. 分块生成嵌入
      const fullText = `${localizedTitle}\n${summary}\n${localizedContent}`;
      const chunks = this.chunkText(fullText);
      const embeddings: number[][] = [];

      for (let i = 0; i < chunks.length; i++) {
        const embedding = await this.aiService.generateEmbedding(chunks[i]);
        if (embedding) {
          embeddings.push(embedding);
        } else {
          this.logger.warn(`Failed to generate embedding for chunk ${i} of article ${articleId}`);
        }
      }

      if (embeddings.length === 0) {
        this.logger.error(`No embeddings generated for article ${articleId} [${locale}]`);
        return false;
      }

      // 6. 获取当前最大版本号
      const latestVersion = await this.prisma.articleEmbedding.findFirst({
        where: { articleId, locale },
        orderBy: { version: 'desc' },
        select: { version: true },
      });
      const newVersion = (latestVersion?.version || 0) + 1;

      // 7. 批量写入嵌入记录
      const records = embeddings.map((emb, index) => ({
        articleId,
        locale,
        contentHash,
        embedding: emb,
        version: newVersion,
        chunkIndex: index,
        status: 'active' as const,
      }));

      await this.prisma.articleEmbedding.createMany({ data: records });
      this.logger.log(`Generated ${records.length} embeddings for article ${articleId} [${locale}] v${newVersion}`);

      return true;
    } catch (error) {
      this.logger.error(`generateEmbedding failed for ${articleId} [${locale}]: ${error.message}`);
      return false;
    }
  }

  /**
   * 语义搜索相似文章
   */
  async searchSimilar(
    query: string,
    options: {
      topK?: number;
      locale?: string;
      minScore?: number;
    } = {},
  ): Promise<Array<{
    articleId: string;
    title: string;
    summary?: string;
    similarity: number;
    chunkIndex: number;
    locale: string;
  }>> {
    const { topK = 10, locale = 'zh', minScore = 0.0 } = options;

    try {
      // 1. 生成查询向量
      const queryEmbedding = await this.aiService.generateEmbedding(query);
      if (!queryEmbedding) {
        this.logger.warn('Query embedding generation failed, returning empty results');
        return [];
      }

      // 2. pgvector 余弦距离搜索（<=> 操作符）
      const embeddingJson = JSON.stringify(queryEmbedding);
      const results = await this.prisma.$queryRaw<any[]>`
        SELECT
          ae."articleId",
          ae.locale,
          ae."chunkIndex",
          ae."contentHash",
          (ae.embedding <=> ${embeddingJson}::vector) AS distance
        FROM article_embeddings ae
        WHERE ae.status = 'active'
          AND ae.locale = ${locale}
          AND ae.embedding IS NOT NULL
        ORDER BY ae.embedding <=> ${embeddingJson}::vector
        LIMIT ${topK * 2} -- 多取一些，后续按文章去重
      `;

      if (!results || results.length === 0) {
        return [];
      }

      // 3. 按文章去重，保留最高相似度分块
      const articleMap = new Map<string, any>();
      for (const row of results) {
        const id = row.articleId;
        const similarity = 1 - Number(row.distance); // 余弦距离 → 相似度
        if (similarity < minScore) continue;

        if (!articleMap.has(id) || similarity > articleMap.get(id).similarity) {
          articleMap.set(id, {
            articleId: id,
            similarity,
            chunkIndex: row.chunkIndex,
            locale: row.locale,
          });
        }
      }

      // 4. 获取文章标题和摘要
      const articleIds = [...articleMap.keys()];
      const articles = await this.prisma.blogArticle.findMany({
        where: { id: { in: articleIds } },
        select: {
          id: true,
          title: true,
          summary: true,
          slug: true,
        },
      });

      const articleTitles = new Map(articles.map((a) => [a.id, { title: a.title, summary: a.summary, slug: a.slug }]));

      // 5. 组装结果，按相似度降序排列
      return [...articleMap.values()]
        .sort((a, b) => b.similarity - a.similarity)
        .slice(0, topK)
        .map((item) => {
          const info = articleTitles.get(item.articleId);
          return {
            articleId: item.articleId,
            title: info?.title || '未知文章',
            summary: info?.summary || undefined,
            slug: info?.slug,
            similarity: item.similarity,
            chunkIndex: item.chunkIndex,
            locale: item.locale,
          };
        });
    } catch (error) {
      this.logger.error(`searchSimilar failed: ${error.message}`);
      return [];
    }
  }

  /**
   * 删除文章的所有嵌入（文章删除时调用）
   */
  async deleteArticleEmbeddings(articleId: string): Promise<void> {
    await this.prisma.articleEmbedding.deleteMany({
      where: { articleId },
    });
    this.logger.log(`Deleted all embeddings for article ${articleId}`);
  }

  /**
   * 同步文章嵌入（多语言）
   */
  async syncArticle(articleId: string, locales: string[] = ['zh', 'en', 'ko', 'ja']): Promise<void> {
    this.logger.log(`Syncing embeddings for article ${articleId}, locales: ${locales.join(', ')}`);

    const results = await Promise.allSettled(
      locales.map((locale) => this.generateEmbedding(articleId, locale)),
    );

    const failures = results.filter((r) => r.status === 'rejected' || (r.status === 'fulfilled' && r.value === false));
    if (failures.length > 0) {
      this.logger.warn(`${failures.length}/${locales.length} locales failed for article ${articleId}`);
    } else {
      this.logger.log(`Successfully synced all locales for article ${articleId}`);
    }
  }
}
```

#### 关键设计说明

- **contentHash 去重**：publish 时计算 `MD5(title|summary|content)`，与现有 active 嵌入对比。一致则跳过，不一致则版本递增
- **分块策略**：每块 1500 字符（约 375 tokens），最多 10 块。长文章按段落边界分割
- **pgvector 搜索**：使用 `<=>` 余弦距离操作符，将距离 `1 - distance` 转为相似度
- **按文章去重**：多分块搜索后，每篇文章只保留相似度最高的分块
- **错误隔离**：单个语言/分块失败不影响其他语言/分块

### Step 3: 创建批量 Embedding 同步队列任务

**文件**: `apps/api/src/blog/processors/blog-ai.processor.ts`

在 `BlogAiProcessor` 中添加新的队列任务处理函数：

```typescript
// 在 process 方法的 switch-case 中添加 'syncArticleEmbeddings' case
case 'syncArticleEmbeddings':
  await this.processSyncArticleEmbeddings(data);
  break;

// 新增处理方法
private async processSyncArticleEmbeddings(data: {
  articleId?: string;     // 可选：指定文章 ID
  locale?: string;        // 可选：指定语言
  batchSize?: number;     // 可选：批处理大小
}): Promise<void> {
  const { articleId, locale, batchSize = 50 } = data;

  // 注入 ArticleEmbeddingService
  const articleEmbeddingService = this.moduleRef.get(ArticleEmbeddingService, { strict: false });

  if (articleId) {
    // 单篇文章同步
    const locales = locale ? [locale] : ['zh', 'en', 'ko', 'ja'];
    await articleEmbeddingService.syncArticle(articleId, locales);
    return;
  }

  // 批量同步所有文章（断点续传）
  let cursor: string | null = null;
  let totalProcessed = 0;
  let totalFailed = 0;

  do {
    const articles = await this.prisma.blogArticle.findMany({
      where: { ...(cursor ? { id: { gt: cursor } } : {}) },
      orderBy: { id: 'asc' },
      take: batchSize,
      select: { id: true },
    });

    for (const article of articles) {
      try {
        const locales = locale ? [locale] : ['zh', 'en', 'ko', 'ja'];
        await articleEmbeddingService.syncArticle(article.id, locales);
        totalProcessed++;
      } catch (error) {
        totalFailed++;
        this.logger.error(`Failed to sync article ${article.id}: ${error.message}`);
      }
    }

    cursor = articles.length === batchSize ? articles[articles.length - 1].id : null;

    // 每批完成后更新进度
    await this.updateJobProgress({
      jobId: this.currentJob?.id,
      processed: totalProcessed,
      failed: totalFailed,
    });

  } while (cursor);

  this.logger.log(`Batch embedding sync complete: ${totalProcessed} succeeded, ${totalFailed} failed`);
}
```
