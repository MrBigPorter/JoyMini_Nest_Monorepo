# 11. 实现写作工具集工厂函数

## 🎯 本步骤目标

为 BlogWritingAgent 创建 **9 个写作工具**，采用 `tool()` API + Zod schema 模式（参考 jisugou-ai-agent 02），分为三类：
1. **研究参考**（3 个）— 搜索已有内容
2. **写作生成**（4 个）— AI 生成内容
3. **收尾辅助**（2 个）— 提取摘要、推荐标签

---

## 📖 背景说明

### 承上

上一步 [10-实现-BlogWritingAgent双模式](10-实现-BlogWritingAgent双模式.md) 定义了双模式架构。两种模式都需要工具支持：
- **ReAct 模式**：工具作为 Agent 的调用能力
- **Workflow 模式**：节点内部调用工具函数

### 这一步要解决的问题

- 工具定义分散 → 集中到 `writing.tools.ts`
- 工具写法不规范 → 统一 `tool()` API + Zod schema
- 工具内部调 LLM → 参考 travel-agent `itineraryTool` 模式

### 设计决策

| 决策 | 选项 | 选择 |
|------|------|------|
| 工具创建模式 | 直接定义 / 工厂函数 | **工厂函数** — 接收 AiService/BlogService，返回 tool 数组（参考 plans/06 OrderAgent 模式） |
| Schema 定义 | 手写 / Zod | **Zod** — 类型安全 + 自动校验 |
| LLM 调用 | 外部传入 / 工具内部 | **工具内部** — 每个写作工具内部调 AiService.generateText |
| 输出格式 | 自由文本 / 结构化 | **结构化** — 统一 `WritingToolResult` 接口 |

## 📝 实现步骤

### Step 1: 定义统一的结果类型和工具注册入口

```typescript
// apps/api/src/blog/agent/tools/writing.tools.ts

import { tool } from '@langchain/core/tools';
import { z } from 'zod';
import { AiService } from '../../../common/ai/ai.service';
import { BlogService } from '../../blog.service';
import { KnowledgeService } from '../services/knowledge.service';

export interface WritingToolResult {
  success: boolean;
  data: string;
  metadata?: Record<string, any>;
}

// 工厂函数：接收服务依赖，返回工具数组
export function createWritingTools(
  aiService: AiService,
  blogService: BlogService,
  knowledgeService: KnowledgeService,
) {
  return [
    createSearchExistingArticlesTool(blogService),
    createGetArticleTool(blogService),
    createSearchKnowledgeTool(knowledgeService),
    createGenerateOutlineTool(aiService),
    createWriteSectionTool(aiService),
    createWriteFullArticleTool(aiService),
    createPolishArticleTool(aiService),
    createSummarizeToAbstractTool(aiService),
    createSuggestTagsTool(aiService),
  ];
}
```

### Step 2: 研究参考类工具（3 个）

#### Tool 1: `search_existing_articles`

搜索已有文章，避免重复创作。直接调用 `BlogService.searchArticles`。

```typescript
export function createSearchExistingArticlesTool(blogService: BlogService) {
  return tool(
    async ({ query, limit, locale }): Promise<string> => {
      const results = await blogService.searchArticles(query, {
        page: 1,
        pageSize: limit || 5,
        locale: locale || 'zh',
      });

      if (results.articles.length === 0) {
        return JSON.stringify({ success: true, data: '未找到相关文章' });
      }

      const summary = results.articles.map((a: any) => ({
        id: a.id,
        title: a.title,
        summary: a.summary?.substring(0, 200),
        locale: a.locale,
        updatedAt: a.updatedAt,
      }));

      return JSON.stringify({
        success: true,
        data: `找到 ${summary.length} 篇相关文章`,
        metadata: { articles: summary },
      });
    },
    {
      name: 'search_existing_articles',
      description: '搜索已有文章，避免重复创作。返回文章标题和摘要列表。',
      schema: z.object({
        query: z.string().describe('搜索关键词'),
        limit: z.number().optional().default(5).describe('返回数量上限'),
        locale: z.string().optional().default('zh').describe('语言'),
      }),
    },
  );
}
```

#### Tool 2: `get_article`

获取单篇文章完整内容。

```typescript
export function createGetArticleTool(blogService: BlogService) {
  return tool(
    async ({ articleId, locale }): Promise<string> => {
      const article = await blogService.getArticle(articleId, false, locale || 'zh');
      return JSON.stringify({
        success: true,
        data: `文章《${article.title}》`,
        metadata: {
          title: article.title,
          content: article.content?.substring(0, 5000),
          summary: article.summary,
          tags: article.tags,
          category: article.category,
        },
      });
    },
    {
      name: 'get_article',
      description: '获取单篇文章的完整内容（标题、正文、标签、分类）',
      schema: z.object({
        articleId: z.string().describe('文章 ID'),
        locale: z.string().optional().default('zh').describe('语言'),
      }),
    },
  );
}
```

### Step 3: 写作生成类工具（4 个）

这些工具内部调用 AiService.generateText 生成内容。

#### Tool 4: `generate_outline`（内部调 LLM）

```typescript
export function createGenerateOutlineTool(aiService: AiService) {
  return tool(
    async ({ topic, locale, style }): Promise<string> => {
      const prompt = `You are a professional blog writer. Create a detailed outline for a blog article with the following specifications:

Topic: "${topic}"
Language: ${locale}
Style: ${style || 'general'}

Return ONLY a JSON array of sections, each with:
- title: section title
- subSections: array of sub-section titles
- keyPoints: array of key points to cover

Example:
[
  {
    "title": "Introduction",
    "subSections": ["Background", "Problem Statement"],
    "keyPoints": ["Why this matters", "What reader will learn"]
  }
]`;

      const result = await aiService.generateText(prompt);
      return JSON.stringify({
        success: true,
        data: result || '大纲生成失败',
        metadata: { topic, style },
      });
    },
    {
      name: 'generate_outline',
      description: '根据主题生成文章大纲，返回结构化的章节列表',
      schema: z.object({
        topic: z.string().describe('文章主题'),
        locale: z.string().optional().default('zh').describe('语言'),
        style: z.enum(['general', 'technical', 'tutorial', 'news']).optional().default('general').describe('文章风格'),
      }),
    },
  );
}
```

> **模式说明**：此工具内部调 `AiService.generateText()` 来生成内容。参考 travel-agent 的 [`itinerary.tool.ts`](study/LLM/project/travel-agent/backend/src/tools/itinerary.tool.ts) — 工具内部创建一个 ChatOllama 实例用于生成。

```typescript
export function createWriteSectionTool(aiService: AiService) {
  return tool(
    async ({ outline, sectionIndex, context, locale }): Promise<string> => {

      return JSON.stringify({
        success: true,
        data: result || '章节生成失败',
        metadata: { sectionIndex },
      });
    },
    {
      name: 'write_section',
      description: '根据大纲写文章某一段落，返回 Markdown 格式',
      schema: z.object({
        outline: z.string().describe('完整文章大纲'),
        sectionIndex: z.number().describe('要写的章节索引（从 0 开始）'),
        context: z.string().optional().describe('前面章节的上下文'),
        locale: z.string().optional().default('zh').describe('语言'),
      }),
    },
  );
}
```

#### Tool 6: `write_full_article`（内部调 LLM — 完整内容生成）

```typescript
export function createWriteFullArticleTool(aiService: AiService) {
  return tool(
    async ({ outline, references, locale, style }): Promise<string> => {
      const refText = references
        ? `\nReference materials:\n${references}`
        : '';

      const prompt = `Write a complete blog article based on the outline below.

Outline:
${outline}
${refText}

Language: ${locale}
Style: ${style || 'general'}

Requirements:
- Write in Markdown format
- Include an engaging title (H1)
- Use proper headings (H2, H3) matching the outline
- Include a brief introduction and conclusion
- Write at least 800 words in ${locale === 'zh' ? 'Chinese' : 'English'}
- Maintain consistent tone throughout`;

      // 注意：这里使用更强大的模型（如 qwen7b/14b）来生成完整文章
      const result = await aiService.generateText(prompt);
      return JSON.stringify({
        success: true,
        data: result || '文章生成失败',
        metadata: { wordCount: result?.length || 0 },
      });
    },
    {
      name: 'write_full_article',
      description: '基于大纲和参考资料一次性生成完整文章，返回 Markdown 格式',
      schema: z.object({
        outline: z.string().describe('文章大纲（包含所有章节）'),
        references: z.string().optional().describe('参考资料（已有文章内容、知识库等）'),
        locale: z.string().optional().default('zh').describe('语言'),
        style: z.string().optional().default('general').describe('写作风格'),
      }),
    },
  );
}
```

```typescript
export function createPolishArticleTool(aiService: AiService) {
  return tool(
    async ({ content, style, locale }): Promise<string> => {
      const prompt = `Polish and improve the following blog article.

Current content:
${content}

Target style: ${style || 'general'}
Language: ${locale}

Improvements needed:
1. Fix grammar and spelling errors
2. Improve sentence flow and readability
3. Enhance vocabulary and expressions
4. Maintain the original meaning and structure
5. Keep the author's voice

Output the polished version in full.`;

      const result = await aiService.generateText(prompt);
      return JSON.stringify({
        success: true,
        data: result || '润色失败',
        metadata: { originalLength: content.length, polishedLength: result?.length || 0 },
      });
    },
    {
      name: 'polish_article',
      description: '润色文章，优化语句流畅度和表达风格',
      schema: z.object({
        content: z.string().describe('原始文章内容（Markdown 格式）'),
        style: z.enum(['general', 'formal', 'casual', 'academic']).optional().default('general').describe('目标风格'),
        locale: z.string().optional().default('zh').describe('语言'),
```

```typescript
export function createSummarizeToAbstractTool(aiService: AiService) {
  return tool(
    async ({ content, maxLength }): Promise<string> => {
      const prompt = `Extract a concise summary/abstract from the following blog article.

Article:
${content.substring(0, 4000)}

Requirements:
- Write in the same language as the article
- Maximum ${maxLength || 200} characters
- Capture the main points and key takeaways
- Suitable for SEO meta description
- Do not use "this article" or "this blog" phrases`;

      const result = await aiService.generateText(prompt);
      return JSON.stringify({
        success: true,
        data: result || '摘要生成失败',
        metadata: { summaryLength: result?.length || 0 },
      });
    },
    {
      name: 'summarize_to_abstract',
      description: '从文章正文提取摘要/SEO 描述，简洁概括核心内容',
      schema: z.object({
        content: z.string().describe('文章正文内容'),
        maxLength: z.number().optional().default(200).describe('摘要最大字符数'),
      }),
    },
  );
}
```

#### Tool 9: `suggest_tags`

```typescript
export function createSuggestTagsTool(aiService: AiService) {
  return tool(
    async ({ content, maxTags }): Promise<string> => {
      const prompt = `Suggest relevant tags for the following blog article.

Article:
${content.substring(0, 3000)}

Requirements:
- Return ONLY a JSON array of tag strings, e.g. ["NestJS", "TypeScript", "Backend"]
- Suggest ${maxTags || 5} to ${(maxTags || 5) + 3} tags
- Tags should be in the same language as the article
- Prefer existing common tags in the system
- Include 1-2 broad category tags and 2-3 specific topic tags
- Each tag should be 1-3 words`;

      const result = await aiService.generateText(prompt);
      // 尝试解析 JSON 数组
      try {
        const tags = JSON.parse(result || '[]');
        return JSON.stringify({
          success: true,
          data: `推荐标签: ${tags.join(', ')}`,
          metadata: { tags },
        });
      } catch {
        return JSON.stringify({
          success: true,
          data: result || '标签推荐失败',
          metadata: { tags: [] },
        });
      }
    },
    {
      name: 'suggest_tags',
      description: '基于文章内容推荐标签，返回标签数组',
      schema: z.object({
        content: z.string().describe('文章内容'),
        maxTags: z.number().optional().default(5).describe('推荐标签数量'),
      }),
    },
  );
}
```

```typescript
describe('createWritingTools', () => {
  const mockAiService = { generateText: jest.fn() };
  const mockBlogService = { searchArticles: jest.fn(), getArticle: jest.fn() };
  const mockKnowledgeService = { search: jest.fn() };

  const tools = createWritingTools(

    mockBlogService as any,
    mockKnowledgeService as any,
  );

  it('应返回 9 个工具', () => {
    expect(tools).toHaveLength(9);
  });

  it('search_existing_articles 应返回文章列表', async () => {
    mockBlogService.searchArticles.mockResolvedValue({
      articles: [{ id: '1', title: 'Test' }],
    });
    const result = await tools[0].invoke({ query: 'NestJS' });
    const parsed = JSON.parse(result);
    expect(parsed.success).toBe(true);
  });

  it('generate_outline 应调用 AiService', async () => {
    mockAiService.generateText.mockResolvedValue('[{"title":"Intro"}]');
    const result = await tools[3].invoke({
      topic: 'NestJS',
      locale: 'zh',
      style: 'technical',
    });
    const parsed = JSON.parse(result);
    expect(parsed.success).toBe(true);
    expect(mockAiService.generateText).toHaveBeenCalled();
  });

  it('suggest_tags 应返回标签数组', async () => {
    mockAiService.generateText.mockResolvedValue(
      '["NestJS", "TypeScript", "Backend"]',
    );
    const result = await tools[8].invoke({
      content: '文章内容...',
      maxTags: 5,
    });
    const parsed = JSON.parse(result);
    expect(parsed.metadata.tags).toContain('NestJS');
  });

  it('工具名应唯一且符合命名规范', () => {
    const names = tools.map((t) => t.name);
    expect(new Set(names).size).toBe(9); // 无重复
    names.forEach((name) => {
      expect(name).toMatch(/^[a-z_]+$/); // snake_case
    });
  });
});
```
