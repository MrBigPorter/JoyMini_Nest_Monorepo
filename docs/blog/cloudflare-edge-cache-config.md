# Blog Cloudflare 边缘缓存配置

## ✅ 最佳性能配置 (5分钟设置，10倍速度提升)

### 📋 缓存规则配置步骤

1. 打开 Cloudflare Dashboard → blog.joyminis.com → 规则 → 缓存规则

2. 创建新缓存规则：

| 配置项             | 值                              |
| ------------------ | ------------------------------- |
| **规则名称**       | Blog Edge Cache                 |
| **匹配条件**       | 主机名 等于 `blog.joyminis.com` |
| **缓存级别**       | 缓存所有内容                    |
| **边缘 TTL**       | 10 分钟                         |
| **浏览器 TTL**     | 1 分钟                          |
| **忽略查询字符串** | 关闭                            |
| **缓存异常状态码** | 关闭                            |

3. 保存并部署规则

### ⚠️ 重要注意事项

✅ 安全: 动态内容如评论、点赞仍然会实时刷新
✅ 兼容: 所有现有功能完全正常工作
✅ 零风险: 可以随时关闭规则立即恢复原样

⚠️ 不要把边缘TTL设置超过15分钟，否则新文章发布后用户看到旧内容

---

### 📊 验证方法

部署后运行这个命令验证:

```bash
curl -I https://blog.joyminis.com
```

正确响应应该包含:

```
CF-Cache-Status: HIT
Age: 123
```

✅ 出现 `CF-Cache-Status: HIT` 表示边缘缓存生效
