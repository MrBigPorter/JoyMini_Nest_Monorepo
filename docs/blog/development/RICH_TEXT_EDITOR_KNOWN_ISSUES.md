## ⚠️ 重要警告：永远不要监听 Quill 的 text-change 事件

这是 React Quill 存在了超过 7 年的经典 Bug，全世界 90% 的集成都犯了这个错误。

```typescript
// ❌ 绝对不要这么做！一定会导致无限循环
quill.on("text-change", () => {
  onChange(quill.root.innerHTML);
});
```

### 正确的方案

所有通过代码修改内容的地方，必须手动调用 `onChange`：

```typescript
//  这是唯一可靠的方案
quill.insertEmbed(index, "image", url);
setTimeout(() => {
  onChange(quill.root.innerHTML);
}, 0);
```
