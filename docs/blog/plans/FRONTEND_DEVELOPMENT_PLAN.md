### 📋 待实现接口规范

> 🔗 **前端UI已完成，等待后端接口对接**

#### 🔐 认证接口

| 接口                         | 状态 | 说明                             |
| ---------------------------- | ---- | -------------------------------- |
| `POST /api/auth/login`       | ⬜   | 邮箱密码登录                     |
| `POST /api/auth/register`    | ⬜   | 用户注册（邮箱、密码、确认密码） |
| `GET /api/auth/oauth/github` | ⬜   | GitHub OAuth登录/注册            |
| `GET /api/auth/oauth/google` | ⬜   | Google OAuth登录/注册            |
| `POST /api/auth/logout`      | ⬜   | 退出登录                         |
| `GET /api/auth/me`           | ⬜   | 获取当前用户信息                 |

> **前端UI已完整实现，包含以下字段**:
>
> - `email` - 邮箱地址
> - `password` - 密码
> - `confirmPassword` - 确认密码（仅注册）
> - OAuth 回调地址需要配置 `/login/callback`
