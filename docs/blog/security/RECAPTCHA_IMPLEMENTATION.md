# ReCaptcha v3 人机验证系统 技术实现文档

## 📋 背景与防爬需求

### 🔴 问题现状

**风险等级**: 防爬风险 🟠

目前系统缺乏机器人防护：

1.  ❌ 评论接口可以被脚本批量调用
2.  ❌ 可以全自动发布垃圾广告评论
3.  ❌ 无法区分真实用户和爬虫
4.  ❌ 没有流量异常检测机制

**攻击场景**:

```bash
# 单IP每分钟可以提交上千条垃圾评论
while true; do
  curl -X POST -d "content=垃圾广告" http://api/blog/comments
done
```

---

## 技术方案

### 设计目标

无感知用户体验，无需点击验证码
0.5 - 1.0 可信度分值评估
低分值请求自动拦截
可配置开关，开发环境关闭
前端无侵入集成

---

### 🎯 验证流程

```mermaid

    A[用户操作页面] --> B[前端后台生成token]

    E -->|> 0.5| F[正常处理请求]
```

### 🏗️ 系统架构

```mermaid
sequenceDiagram
    participant 浏览器
    participant 前端
    participant 后端API
    participant Google ReCaptcha

    浏览器->>前端: 页面加载
    前端->>Google ReCaptcha: 加载v3脚本
    Google ReCaptcha-->>前端: 初始化完成

    浏览器->>前端: 点击提交评论
    前端->>Google ReCaptcha: 获取验证token
    Google ReCaptcha-->>前端: 返回token

    前端->>后端API: 提交数据 + token
    后端API->>Google ReCaptcha: siteverify 请求
    Google ReCaptcha-->>后端API: 返回score 0.0-1.0

    alt 分值 > 0.5
        后端API->>数据库: 保存评论
        后端API-->>前端: 成功
    else 分值 < 0.5
        后端API-->>前端: 验证失败 请刷新页面
    end
```

## 🚀 技术选型

| 组件     | 选型         | 说明               |
| -------- | ------------ | ------------------ |
| 验证版本 | reCAPTCHA v3 | 无交互，返回分值   |
| 阈值配置 | 0.5 默认     | 可动态调整         |
| 异常处理 | 降级模式     | Google不可用时放行 |
| 集成方式 | NestJS Guard | 透明拦截           |

## 📌 实现细节

### 分值处理策略

| 分值范围  | 处理方式                  |
| --------- | ------------------------- |
| 0.7 - 1.0 | 正常人类用户，直接通过    |
| 0.5 - 0.7 | 可疑用户，进入审核队列    |
| 0.3 - 0.5 | 拒绝请求，提示刷新        |
| 0.0 - 0.3 | 确认机器人，临时封禁1小时 |

### 性能指标

- 验证耗时: ~100ms
- 并发支持: 无限制
- 失败降级: 自动绕过不影响使用
