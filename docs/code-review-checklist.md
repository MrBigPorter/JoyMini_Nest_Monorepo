# Code Review 检查清单

## 每次 Review 按顺序过这 7 步

### Step 1：对称性 — "有加就有减"

检查每次 `create` / `add` / `incr` / `open` 有没有对应的 `delete` / `remove` / `decr` / `close`。

| 常见遗漏                                      | 上次 bug  |
| --------------------------------------------- | --------- |
| tryAcquire 加了 IP incr，release 没写 IP decr | ✅ 问题 1 |
| 数据库 INSERT 没写对应的 DELETE               | -         |
| 锁 acquire 没写 release                       | -         |

### Step 2：边界值 — "零、一、很多"

| 场景 | 检查                            |
| ---- | ------------------------------- |
| 空值 | 参数为 null/''/[] 时会不会崩？  |
| 单条 | 只有 1 条数据时逻辑对不对？     |
| 上限 | 超过上限时处理对不对？          |
| 负数 | 计数器会不会变负数？上次 bug ✅ |

### Step 3：竞争条件 — "如果同时发生"

| 场景                   | 检查                                     |
| ---------------------- | ---------------------------------------- |
| 两个人同时点确认       | 数据库锁 / 原子操作                      |
| Key 过期了但代码还在用 | 检查 TTL 和处理逻辑                      |
| 先读后写               | 是不是应该用原子操作（Lua / Redis INCR） |

### Step 4：异常路径 — "如果挂了"

| 场景     | 检查                   |
| -------- | ---------------------- |
| 网络超时 | 有没有 try-catch       |
| 依赖挂了 | 降级逻辑对不对         |
| 部分失败 | 部分成功的数据怎么回滚 |

### Step 5：用户体验 — "用户看到什么"

| 场景   | 检查                 |
| ------ | -------------------- |
| 加载中 | 有没有 loading 状态  |
| 空数据 | 空状态提示           |
| 错误   | 用户看得懂的错误信息 |
| 成功   | 操作成功后反馈       |

### Step 6：安全 — "能不能被攻击"

| 场景             | 检查                             |
| ---------------- | -------------------------------- |
| 注入             | 参数有没有校验                   |
| 越权             | 用户 A 能不能操作用户 B 的数据   |
| 敏感数据         | 返回的 JSON 有没有不该暴露的字段 |
| Prompt Injection | AI 能不能被诱导执行危险操作      |

### Step 7：性能 — "扛不扛得住"

| 场景     | 检查                     |
| -------- | ------------------------ |
| N+1 查询 | 循环里有没有查数据库     |
| 大 key   | 一次读写数据量会不会太大 |
| 连接泄漏 | 连接用完有没有 close     |

---

## Review 流程

```
作者提交 PR →  Reviewer 按 7 步检查 → 发现问题 → 作者修改
                                       ↓
                                   没问题 → 合并
```

**每条 Review 意见必须包含：**

```
❌ 问题: IP decr 没写，计数只增不减
🔍 根因: 对称操作遗漏
💊 修复: release() 加两行
⚠️ 后果: 跑一星期后 IP 限流误杀
```
