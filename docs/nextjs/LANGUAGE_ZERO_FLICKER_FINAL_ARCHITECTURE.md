# 语言零闪烁最终架构 v2.0

> **最终稳定版**：经过长达3个月迭代的最终完美方案，彻底解决所有语言同步、闪烁、时序问题

---

## 🎯 核心设计原则

### 唯一真理原则

**整个系统只有一个语言检测数据源** `detectLocale()`
**所有模块必须统一使用这个函数，禁止任何重复实现**

### 优先级设计 (终极正确)

| 优先级 | 数据源                | 说明                     |
| ------ | --------------------- | ------------------------ |
| 🔝 1   | NEXT_LOCALE Cookie    | 用户明确意图，最高优先级 |
| 2      | URL路径               | 呈现层状态               |
| 3      | 浏览器Accept-Language | 首次访问检测             |
| 4      | 默认语言              | 兜底                     |

## 📐 系统架构

```
┌───────────────────────────────────────────────────┐
│                   detectLocale()                  │
│  全局唯一语言检测函数  整个系统唯一可信数据源    │
└─────────────────────┬─────────────────────────────┘
                      │
  ┌───────────────────┼───────────────────┐
  │                   │                   │
┌─▼────┐          ┌───▼────┐         ┌────▼───┐
│ 中间件 │        │ HTTP客户端 │       │ I18nProvider │
│ 路由  │        │ API请求  │       │ 静态翻译  │
└────────┘        └──────────┘       └──────────┘
```

**所有模块从同一数据源读取语言**
**没有任何独立的语言检测逻辑**
**100% 状态一致性**

---

## 最终行为保证

语言切换时序：

1.  用户点击切换语言按钮
2.  **立即设置NEXT_LOCALE Cookie**
3.  **所有后续API请求立即使用新语言**
4.  **所有静态翻译文本立即更新**
5.  **I18nProvider发现不一致立即同步路由**
6.  **整个过程零闪烁、零延迟、零不一致**

## 📝 代码实现规范

### 🔴 绝对禁止

- ❌ 禁止在任何地方重复实现语言检测逻辑
- ❌ 禁止直接读取window.location判断语言
- ❌ 禁止硬编码默认语言
- ❌ 禁止依赖localStorage存储语言状态
- ❌ 禁止导入不存在的导出函数

### ⚠ 特殊例外

> 唯一例外：`src/app/page.tsx` 根页面
>
> 根页面是Next.js 15中唯一一个**不能**使用`detectLocale()`的地方，因为在根路由上下文还没初始化完成。
>
> 根页面必须手动实现最小化检测逻辑，直接使用`LOCALES.includes()`进行验证。
>
> 这是整个系统中唯一允许的例外情况。

### 🟢 正确做法

- 所有语言检测必须调用 `detectLocale()`
- 语言状态唯一存储在 `NEXT_LOCALE` Cookie
- 优先级永远是 Cookie > 路径
- I18nProvider负责同步路由状态
