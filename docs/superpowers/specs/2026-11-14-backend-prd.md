# 后端 PRD

> 日期：2026-11-14
> 范围：NestJS 服务（`apps/api`）
> 定位：把系统从「单机能跑」推到「可部署、可恢复、可计量」
> 关联：`2026-11-14-enterprise-readiness-design.md`

---

## 1. 目标

后端目前能在一台机器上完整跑通。问题不是功能缺失，而是**三类假设在真实部署下不成立**：

```
假设一：进程不会重启        → MemorySaver 存会话状态
假设二：只有一个实例        → 事件总线与 Socket 房间都是进程内的
假设三：消息不会丢          → AI 请求只在内存里排着，异常只落日志
```

本 PRD 要求：这三条假设被替换成可验证的工程约束。

## 2. 用户与场景

| 用户 | 场景 | 关心什么 |
|---|---|---|
| 业务方 | 客服系统 7×24 运行 | 重启后会话别丢、消息别静默消失 |
| 运维 | 机器扩容 | 多实例后行为不变 |
| 财务/运营 | 成本 | 单会话花了多少、超预算怎么办 |

## 3. 功能需求

### F1 会话状态持久化

- 会话级状态（当前意图、待确认动作、重复计数、流程状态）必须落在数据库中，**不依赖进程内存**。
- 进程重启后，用户继续同一会话，上下文应与重启前一致。
- 无数据库环境（本地裸跑）允许降级到内存实现，但必须打出显式告警。

**验收**：重启后端后，同一会话的 `previousIntent`、`messages`、`flowState` 保留；降级路径有 `warn` 日志。
（注：`pendingConfirm` 不在 `AgentState` 中，确认令牌存 Redis，本就不受重启影响。）

### F2 异步任务可靠投递

- 用户消息落库后触发的 AI 处理，必须经由持久化队列，不得只依赖进程内事件。
- 任务必须有幂等键，键取 `messageId`；当前事件 payload 只有 `conversationId/content/userId`，需补 `messageId`。
- 同一消息重复投递只处理一次，语义为**丢弃第二次**（不返回第一次结果，避免多等待）。
- 失败任务可重试，超过次数进入死信并告警。

**验收**：模拟进程在任务执行中崩溃，重启后任务可被重新消费且不产生重复回复。

### F3 多实例消息投递

- Socket 房间的消息投递必须在多实例间生效。
- 客户端连在 A 实例、消息产生在 B 实例时，仍能收到。

**验收**：本地两副本，交叉验证双向投递。

### F4 成本计量与护栏

- **两级计数**：用户日累计（防滥用，超限拒绝新会话）+ 单会话累计（防单轮跑飞，超限降级为静态话术并转人工）。
- 两级都超限时，以单会话降级优先。
- 触发时写结构化事件，携带作用域、token 数与阈值。
- 运营可查询当日消耗与触发次数。

**验收**：压低阈值触发降级，日志出现 `cost.guard`，行为变化可观测。

### F5 可观测性补齐到指标层

- 现有结构化日志保留。
- 新增可聚合的关键指标：意图分布、各阶段耗时、单会话 token、转人工原因分布、AI 独立解决率。

**验收**：给定一段时间的数据，能算出「AI 独立解决率」与「P95 首响时长」，不依赖人工翻日志。

### F6 安全边界

- 鉴权信息（用户身份）不得由模型或请求体提供，只能来自 token。
- 管理端操作人只从 JWT 取。
- 长连接凭证不得出现在访问日志中。

**验收**：构造越权请求全部被拒；Nginx 访问日志中无 token 明文。

## 4. 非功能需求

| 编号 | 要求 |
|---|---|
| N1 | 现有单测保持绿；新增能力需有对应测试 |
| N2 | 资金相关代码不做语义变更（条件更新语句不得改写） |
| N3 | 新依赖不得引入付费服务 |
| N4 | 本地启动内存峰值不显著上升（Colima 4GB 约束） |
| N5 | 迁移可回滚或可兼容旧数据（expand/contract） |

## 5. 现有能力盘点

已具备，不需要重做：

- 数据库条件更新（CAS）与单一结算出口
- 结构化日志 + traceId（AsyncLocalStorage）
- 两阶段 SSE + Redis 限流 + 熔断
- 部署流水线（迁移 → 换镜像 → 健康检查 → 自动回滚）
- BullMQ 依赖已引入（现用于 RAG embedding 队列）

## 6. 不做

- 多租户隔离
- 微服务拆分
- 服务网格 / K8s
- 跨区域容灾

## 7. 验收总表

- [ ] 重启不丢会话状态
- [ ] 两副本交叉投递成功
- [ ] 崩溃后任务可重试且不重复回复
- [ ] token 超阈值触发降级并留痕
- [ ] 能算出 AI 独立解决率与 P95
- [ ] 越权请求全拒，日志无 token 明文
- [ ] 全量单测绿色
