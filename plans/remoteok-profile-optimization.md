## 5️⃣ 日常搜索指南

### 5.1 Remote OK 岗位量说明

Remote OK 不是 LinkedIn 那种海量平台。它是一个**小而精**的远程聚合器，每天发布的新岗位大概 **10-30 个**。所以:

- 搜 "full stack" 只有 1 个结果是**正常的**
- 不要指望每天都有几十个岗位
- 关键是要 **换不同关键词** 去捞不同方向的岗位
- 同时 **跨多个平台** 投递

### 5.2 主站搜索

打开 [remoteok.com](https://remoteok.com)，直接搜关键词。

**推荐搜索词组合**（每天全搜一遍）:

| 搜索词 | 预计结果量 | 说明 |
|--------|-----------|------|
| `full stack` | 1-5 个 | Full-Stack Engineer / Full Stack Developer |
| `react` | 3-10 个 | 前端/全栈岗位（量最大） |
| `next.js` 或 `nextjs` | 1-3 个 | Next.js 专项 |
| `nestjs` 或 `node` | 1-3 个 | 后端岗位 |
| `typescript` | 2-5 个 | 覆盖所有 TS 岗位 |
| `flutter` | 1-3 个 | Flutter 移动端（竞争少） |
| `frontend` 或 `front end` | 2-5 个 | 前端岗位 |
| `backend` 或 `back end` | 1-3 个 | 后端岗位 |
| `developer` | 3-8 个 | 最宽泛，捞漏网之鱼 |
| `engineer` | 3-8 个 | 同上 |

> 所有搜索都加上 Filter: **Last 24 hours** + **Worldwide**

**搜索技巧**:
- Remote OK 默认只搜**标题**，不搜描述内容
- 搜 `full stack` 比 `full-stack` 更好（有些公司标题写 Full Stack 不带连字符）
- 搜 `nextjs` 和 `next.js` 都要试（不同公司写法不同）
- 搜 `react` 能覆盖到很多用 React 但标题写 Frontend 的岗位

### 5.3 Filter 使用

搜索页面右侧有 Filter 面板:

| Filter | 设置 |
|--------|------|
| **Category** | Engineering / Full-Stack Development |
| **Region** | Worldwide (全部远程) |
| **Posted** | **Last 24 hours** — 最重要！ |
| **Tag** | 不用手动选，搜索结果自动匹配你 profile 的 tags |

> 💡 关键是 **Posted 选 "Last 24 hours"** — Remote OK 热门岗位很快收满，早投早占坑

### 5.4 你的 Tags 如何帮你被搜索到

当雇主搜索后端/NestJS/Full-Stack 方向的 candidate 时，系统会根据你的 30 个 tags 做匹配:

### 5.6 Easy Apply vs 跳转官网

- **Easy Apply** — Remote OK 内有申请按钮，直接投（你的 profile 就是简历）
- **跳转官网** — 点 "Apply" 跳到公司官网/Workable/Greenhouse 等平台投递
  - 跳转官网时，用你的 cover letter 模板改一下，附上 blog.joyminis.com 的文章链接

### 5.7 多渠道优先级（来自 remote-job-platforms.md）

```
Tier 1:  Turing.com → Himalayas → Arc.dev → HN Who's Hiring → Remote OK
Tier 2:  Wellfound → StackOverflow Jobs
Tier 3:  OnlineJobs.ph (菲律宾特化)
```
