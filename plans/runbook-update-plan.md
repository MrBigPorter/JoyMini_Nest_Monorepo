## 写作原则

1. **说人话** - 避免术语，或用大白话解释
2. **直接给命令** - 复制粘贴就能用，不要占位符
3. **告诉用户什么时候用** - 每个操作前加"什么时候用"
4. **常见坑提前说** - 用 ⚠️ 标出
5. **先给结论，再给原理** - 不想看原理的可以直接跳过

### 2.3 ⚠️ 最容易犯的错
❌ docker restart lucky-backend-prod
    → 没用！restart 不会重新读取配置文件

✅ 要用这个命令：
   cd /opt/lucky && docker compose -f compose.prod.yml --env-file deploy/.env.prod up -d --no-build --force-recreate backend

   翻译成人话：告诉 Docker "用新的配置文件，重新创建一个后端容器"

### 2.4 为什么 restart 不行？（不想看可以跳过）
Docker 容器就像一台组装好的电脑。restart 只是按重启键，里面的配置不变。
--force-recreate 是重新组装一台电脑，这时候才会用新的配置单。
